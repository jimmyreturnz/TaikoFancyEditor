# Taiko Fancy Arranger v3.2.1

Internal maintenance release. No user-visible changes.

## What changed

- Removed a duplicate, dead `open_map` method in the editor window.
- Split the ~6,800-line `MainWindow` class: song-library browsing/scanning
  and the global tool-row/active-view tracking now live in their own
  classes (`LibraryPageController`, `ToolStateController`), reducing
  `MainWindow` by roughly 550 lines. Behavior is unchanged — the full test
  suite passes identically before and after each step.
- Investigated a suspected playback stutter under heavy maps. It turned
  out to be a one-time ~65-frame cold start when views first begin
  rendering (Qt's own compositing/backing-store setup), not a recurring
  problem: once warm, frame cost stays comfortably inside the
  8.33ms/120fps budget (measured max 3.18ms on a 2,097-note synthetic
  map). No fix was needed, and none was made.

## Why release this

Nothing here is visible in the app. This exists to mark a known-good
point in the source history after a structural cleanup pass.
