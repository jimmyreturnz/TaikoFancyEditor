# Taiko Fancy Arranger v3.3.0

A gimmick-editor release: a second anti-barline gimmick, one way into every
converter, snapping that matches osu! exactly, and fixes across copy/paste, the
SV generator's curves and the fake slider layer.

## New

- **Hidden anti-barline**, in the barline layer's **Convert Notes**. The
  anti-barline you already had builds a wall of packed barlines and leaves gaps
  out of it; this one is that trick inside out. A single meter-1 red line makes
  osu! draw the whole sheet, and each note's slit is opened by raising SV for a
  fraction of a beat — four lines per note instead of hundreds. Because taiko
  places an object at its distance times the speed at its own time, the slit
  **opens with distance and closes at the hit position**: the note's colour is
  readable while it is far away and gone by the time you hit it. Reference:
  mew's *LuzeriA - Nbt-Hwt [The Pharaoh's Curse]* 1:56.9–2:07.3, reproduced
  exactly.
- **Convert Notes is the one way into every converter.** The barline layer asks
  which structure first — barline notes, anti-barline, or hidden anti-barline —
  and the fake slider layer asks only for its numbers. The numbers are asked
  **per call** and are not written back to the layer's Config, so a section that
  wants wider slits than the last one is no longer a reason to re-save the
  layer. The separate Anti-barline tool button is gone: it could only ever use
  the saved numbers.
- **Hide note**, on every Don/Kat structure (default on, which is what these
  structures always did). Off, the line on the note's own millisecond carries
  the chart's own BPM with its barline detached, so the note stays visible
  inside its own structure instead of being squashed off screen.
- **Multiple Fake Slider previews the whole run** under the cursor — every
  slider it is about to place, at the size Shift will give them — instead of one
  dot that said nothing about what a click would do.
- **A plain fake slider's red line is now a Config toggle** (default on). It has
  no note to hide, so at the default multiplier that line only restates the BPM
  already in force; a run of them wrote one dead line per slider.

## Changed

- **Snapping matches osu!'s truncation.** A snapped position goes *down* to the
  whole millisecond, not to the nearest one — measured over 25 installed maps,
  where every circle on a clean single-BPM map sits within 1ms *below* its exact
  beat position and never above it. Re-snapping `Hiyashi 2014`'s Oni: rounding
  disagreed with osu! on 100 of its 203 snapped notes, truncation on none. The
  gridline, the wheel seek, placement and paste all go through it; Ctrl
  placement still uses the nearest millisecond, because that one is the pointer's
  position and not a beat.
- **The fake slider layer no longer carries the chart's own SV.** A shiny's
  green line is gone, and these structures no longer get a restore handle
  written for them — a fake slider is decoration, and handing it the speed of
  whatever section it was dropped in made identical structures scroll
  differently. The cost is deliberate: layer 5 arrives with nothing on its
  milliseconds until you put a line there.
- **Finisher notes are drawn bigger** in the editor timeline and the gimmick
  layers — the ruleset's own 1.538x a normal note instead of 1.35x, the same
  proportion the gameplay preview draws. The hit test reads the same number, so
  a finisher is grabbable over its new body.
- **SV is typed to 8 decimal places** and still labelled at 2. Under a 60000 BPM
  line the SV that moves a note a visible distance differs from its neighbour
  past the sixth decimal, and 8 decimals on every point in the graph is a smear.

## Fixed

- **Copy/paste landed one millisecond off.** The paste anchor rounded to the
  nearest millisecond while everything else truncated, so pasting a pattern a
  few beats along kept putting it 1ms past the playhead on any beat whose
  fractional part was at least .5. Hand-placed gimmick structures had the same
  1ms disagreement with the chart's own notes.
- **Copying a gimmick lost its green line.** A Don/Kat fake slider's SV is what
  takes the squashed note off screen, so a pasted copy was a squashed but still
  visible note. Green lines now travel with the structure, ordered behind the
  red line sharing their millisecond so osu! does not cancel them.
- **Pasting SV in a gimmick layer ignored the layer's offset.** A layer owns
  both an object's own millisecond and the one its offset points at, so a paste
  had two targets per object and filled both — with layer 4's default -5ms
  offset, four copied lines covered two notes. A paste now lands where Generate
  lands: one line per object, at the layer's offset.
- **The SV generator's "true exponential" bent the same way for every range.**
  It was a fixed curve that happened to hit both endpoints, so a 1.0 → 10.0
  sweep was 0.52x out at its own midpoint. It is a geometric sweep now — a
  constant factor per step — which is what makes a range's own size decide how
  hard it bends.
- **Sin In and Sin Out were the wrong way round** against TaikoEditor, whose
  names these are. The same-named curve in either editor now writes the same
  numbers.
- **Buttons clipped their own labels when checked.** A checked pink button is
  wider than the same button unchecked (a border and a heavier weight the size
  hint does not report), so the selected tool in every gimmick row ate the last
  letter of its label.
- **A view frame holding more than one view refreshed only the first of them.**
- **The snap grid cost 15.3ms of a 16.3ms frame** on an extreme chart (a 12345
  BPM anti-barline wall), against an 8.33ms budget, by drawing a solid rectangle
  one line at a time: 1422 ticks 1.15px apart. It is bounded by the widest tick
  pen now, and a section too fine for that is drawn at a coarser divisor of the
  setting rather than dropped — 15.3ms → 4.3ms.
