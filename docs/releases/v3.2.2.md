# Taiko Fancy Arranger v3.2.2

A bug-fix release: editor navigation, note dragging, the SV generator, background saving, and library scanning.

## Fixed

- **Editor page went blank after returning to it directly.** Leaving the editor for the Songs tab and then clicking straight back into the Editor tab (without picking a song again) used to leave the workspace empty. The editor's views now rebuild whenever the Editor tab is entered, not only when a song is (re)opened.
- **Don/kat couldn't be dragged to a new position in the regular editor.** A note already in the current selection can now be click-dragged to move it; an unselected note (or empty space) still drag-selects, and a plain click still deselects, same as before.
- **SV generator rounded away the speed it was supposed to match.** The Initial/Final rate and BPM fields were capped at 2 decimal places, silently rounding a prefilled "nearest existing SV/BPM" value before Generate ever used it. They now keep 4.
- **SV generator duplicated a line that was already there.** Generating over a range that already had a green line at one of its positions left that line untouched and added a second, offset one beside it. It now updates that line's speed in place instead.
- **Fancy Arranger backgrounds didn't actually save.** Dropping a background image onto the canvas updated the preview but never marked the difficulty as changed, so Ctrl+S reported "Nothing to save." and silently skipped writing it.
- **Song library:** added a **Quick Scan** button for a fast incremental scan (reuses anything unchanged since the last scan); **Rescan** is relabeled to describe what it actually does — a full rebuild of the index.

## Why release this

Six real, reproducible bugs, each with a regression test. No new features.
