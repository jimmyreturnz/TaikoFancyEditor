
# Taiko Fancy Arranger v1.0.0

Initial public release.

## Highlights

- Interactive osu!taiko map loading and audio preview
- Timeline selection, density visualization, beat snapping, and Kiai highlighting
- Difficulty switching within a song folder
- Pattern preview and commit workflow with undo/redo
- Text, equation, Pinwheel, Taiko, geometric, random-walk, and bouncing transformations
- Don/Kat split transformations
- Beatmap background rendering and drag-and-drop replacement
- Portable Windows x64 build

## Windows installation

1. Download `TaikoFancyArranger-Windows-x64.zip`.
2. Extract the complete archive.
3. Run `TaikoFancyArranger.exe`.

## Important

Back up beatmaps before editing. The application provides backup and export features, but users remain responsible for their map files.
